# alapi-config

Настройка рекламного места в приложении Alapi. Приложение читает `ads.json`
отсюда не чаще раза в 12 часов, так что правка доезжает до людей примерно за
полсуток — без новой сборки и ревью App Store.

Репозиторий публичный: приложение читает файл без пароля. Здесь лежат только
настройка, картинки баннеров и страницы для App Store — ничего секретного.

Страницы (GitHub Pages): [поддержка](https://aslany16.github.io/alapi-config/support.html),
[политика конфиденциальности](https://aslany16.github.io/alapi-config/privacy.html) —
на вторую ссылается и приложение, и App Store; переименовывать нельзя.

## ads.json

| Поле | Что делает |
| --- | --- |
| `enabled` | Рубильник: `false` — рекламы нет. |
| `provider` | `house` — свой баннер (картинка или текст + ссылка). |
| `title`, `subtitle` | Текст баннера, если картинки нет: крупная строка и мелкая под ней. |
| `image` | Картинка баннера (HTTPS). Кладётся в эту же папку, ссылка — `raw.githubusercontent.com/...`. |
| `link` | Куда ведёт касание. |
| `advertiser` | Рекламодатель для маркировки: «ИП Иванов», «ООО Ромашка». |
| `erid` | Токен маркировки из ОРД. Для рекламы по договору обязателен. |
| `minBuild` | Не показывать в сборках старее этой. |

Выключить рекламу — `"enabled": false`. Битый JSON тоже означает «рекламы нет».
